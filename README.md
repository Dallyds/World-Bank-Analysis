# 🌍 World Bank Analytics – Global Development & Data Analytics

A comprehensive data analytics project exploring global economic, demographic, and environmental trends using World Bank and Our World in Data datasets.

This project analyzes over **200+ countries** across **1960–2026**, combining Python-based analytics with interactive Power BI dashboards to uncover patterns in GDP growth, population dynamics, life expectancy, and CO₂ emissions.

---

## 📌 Project Overview

In a data-driven world, understanding global development requires more than isolated statistics. This project creates a unified analytical framework that combines economic, social, and environmental indicators into meaningful insights.

The analysis spans:

* 🌐 200+ Countries
* 📅 1960–2026 Historical Coverage
* 📊 5 Key Development Metrics
* 💰 Multiple Income Groups & Regions

The project is designed for:

* Researchers
* Students
* Data Analysts
* Business Intelligence Professionals

## 🧹 Data Preparation Pipeline

Raw global datasets often contain missing values, inconsistencies, and duplicate records. A structured preprocessing workflow was implemented.

### Data Cleaning Steps

| Step | Action                         | Purpose                        |
| ---- | ------------------------------ | ------------------------------ |
| 1    | Median-based imputation        | Handle missing values          |
| 2    | Duplicate removal & validation | Maintain data integrity        |
| 3    | Derived metric creation        | GDP per capita, CO₂ per capita |
| 4    | Growth percentage calculations | Trend analysis                 |
| 5    | IQR outlier detection          | Identify statistical anomalies |
